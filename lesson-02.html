الدرس 02: أول برنامج لك + دالة print و input

🐍 Python⏱️ 25 دقيقة📊 مبتدئ📝 10 أسئلة

في هذا الدرس سنكتب أول برامجنا الحقيقية ونتعلم أهم دالتين للمبتدئين: print لطباعة النتائج، و input لاستقبال بيانات من المستخدم.

1. دالة print

دالة print تستخدم لعرض أي شيء على الشاشة. يمكنك طباعة نصوص، أرقام، أو حتى نتائج عمليات حسابية.

print("مرحباً بك في Medo El Jan")
print(100)
print(50 + 30)
print("النتيجة =", 50 + 30)

لاحظ أنك تستطيع طباعة أكثر من قيمة في نفس السطر بفصلها بفاصلة.

2. النصوص (Strings)

أي كلام تضعه بين علامتي اقتباس " " أو ' ' يعتبر نصاً (String). يمكنك دمج النصوص معاً باستخدام علامة +.

name = "أحمد"
print("أهلاً " + name)
print("أهلاً", name)  # طريقة أخرى

3. دالة input

دالة input تسمح للمستخدم بإدخال بيانات أثناء تشغيل البرنامج. دائماً ما تُرجع القيمة كنص (string).

name = input("ما اسمك؟ ")
print("مرحباً بك يا", name)

عندما تشغّل هذا الكود سيتوقف البرنامج وينتظر منك كتابة اسمك ثم الضغط على Enter.

4. تحويل أنواع البيانات

بما أن input دائماً يرجع نصاً، إذا أردت استخدام الرقم في عمليات حسابية يجب تحويله:

age = input("كم عمرك؟ ")
age = int(age)  # تحويل من نص إلى رقم صحيح
print("بعد 5 سنين سيكون عمرك", age + 5)

يمكنك استخدام int() للأرقام الصحيحة، و float() للأرقام العشرية.

5. مثال كامل

print("=== برنامج الترحيب ===")
name = input("اكتب اسمك: ")
age = int(input("اكتب عمرك: "))
print("--------------------")
print("أهلاً وسهلاً", name)
print("عمرك الحالي:", age)
print("بعد 10 سنوات سيكون عمرك:", age + 10)
print("شكراً لاستخدامك برنامج Medo El Jan")

ملخص

تعلمنا كيف نطبع معلومات على الشاشة باستخدام print، وكيف نستقبل بيانات من المستخدم باستخدام input، وكيفية تحويل النصوص إلى أرقام. هذه المهارات أساسية جداً في كل البرامج القادمة.
