الدرس 01: مقدمة إلى لغة Python وتثبيت البيئة

🐍 Python ⏱️ 20 دقيقة 📊 مستوى: مبتدئ 📝 10 أسئلة

مرحباً بك في أول درس من مسار تعلم لغة Python! في هذا الدرس سنتعرف على اللغة بشكل عام، ونثبت الأدوات اللازمة لنبدأ الكتابة فوراً.

1. ما هي لغة Python؟

Python هي لغة برمجة عالية المستوى، مفسّرة (Interpreted)، وسهلة التعلم. صممها الهولندي جويدو فان روسوم عام 1991، وأصبحت اليوم من أكثر اللغات استخداماً في العالم.

تتميز Python بقراءتها الشبيهة باللغة الإنجليزية، مما يجعلها مثالية للمبتدئين وللمحترفين على حد سواء.

2. لماذا نتعلم Python؟

هناك أسباب كثيرة تجعل Python خياراً ممتازاً:

- سهولة التعلم والقراءة
- مجتمع ضخم ودعم هائل
- تستخدم في مجالات متعددة: تطوير الويب، تحليل البيانات، الذكاء الاصطناعي، الأتمتة، الألعاب
- مكتبات جاهزة تقريباً لكل شيء
- مطلوبة بشدة في سوق العمل

3. تثبيت Python

اذهب إلى الموقع الرسمي python.org وحمّل أحدث إصدار مستقر (يفضل 3.11 أو أحدث).

أثناء التثبيت على ويندوز، تأكد من تفعيل خيار "Add Python to PATH" حتى تتمكن من استخدام الأمر python من سطر الأوامر.

بعد التثبيت، افتح Terminal أو Command Prompt واكتب:

python --version

إذا ظهرت نسخة Python فهذا يعني أن التثبيت نجح.

4. تثبيت محرر الأكواد VS Code

ننصح بشدة باستخدام Visual Studio Code. حمّله من code.visualstudio.com ثم ثبّت إضافة Python الرسمية من Microsoft.

بعد التثبيت يمكنك إنشاء ملف جديد بامتداد .py وبدء الكتابة فوراً.

5. أول تجربة

افتح VS Code، أنشئ ملفاً باسم hello.py واكتب فيه:

print("مرحباً بك في عالم Python مع Medo El Jan")

ثم شغّل الملف. إذا ظهرت الرسالة فهذا يعني أنك جاهز تماماً للدرس القادم!
