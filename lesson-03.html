الدرس 03: المتغيرات وأنواع البيانات الأساسية

🐍 Python⏱️ 30 دقيقة📊 مبتدئ📝 10 أسئلة

المتغيرات هي صناديق نضع فيها البيانات لنستخدمها لاحقاً في البرنامج. في هذا الدرس سنتعلم كيف ننشئ المتغيرات وما هي أنواع البيانات الأساسية في Python.

1. ما هو المتغير؟

المتغير هو اسم يشير إلى قيمة مخزنة في ذاكرة الحاسوب. يمكنك تخيل أنه صندوق له اسم، وتضع بداخله شيئاً (رقماً أو نصاً أو أي شيء).

name = "Medo"
age = 25
height = 1.75
is_student = True

2. قواعد تسمية المتغيرات

- يجب أن يبدأ بحرف أو شرطة سفلية _
- يمكن أن يحتوي على حروف وأرقام وشرطة سفلية فقط
- لا يمكن أن يبدأ برقم
- لا يمكن استخدام الكلمات المحجوزة مثل if, for, print
- Python حساسة لحالة الأحرف (name تختلف عن Name)

# صحيحة
user_name = "أحمد"
_age = 20
score2 = 95

# خاطئة
2score = 95      # يبدأ برقم
user-name = "أحمد"  # يحتوي على شرطة

3. أنواع البيانات الأساسية

1. الأعداد الصحيحة (int)

x = 10
y = -5
print(type(x))  # <class 'int'>

2. الأعداد العشرية (float)

pi = 3.14
price = 19.99
print(type(pi))  # <class 'float'>

3. النصوص (str)

message = "مرحباً بالعالم"
letter = 'A'
print(type(message))  # <class 'str'>

4. القيم المنطقية (bool)

is_active = True
is_admin = False
print(type(is_active))  # <class 'bool'>

4. معرفة نوع المتغير

استخدم الدالة type() لمعرفة نوع أي متغير:

print(type(100))
print(type(3.14))
print(type("نص"))
print(type(True))

5. التحويل بين الأنواع

num_str = "50"
num_int = int(num_str)      # نص → رقم صحيح
num_float = float(num_str)  # نص → رقم عشري
text = str(100)             # رقم → نص
print(num_int + 10)         # 60

6. مثال عملي

print("=== بيانات الطالب ===")
student_name = input("اسم الطالب: ")
student_age = int(input("عمر الطالب: "))
student_gpa = float(input("المعدل: "))
is_passed = student_gpa >= 2.0

print("--------------------")
print("الاسم:", student_name)
print("العمر:", student_age)
print("المعدل:", student_gpa)
print("ناجح؟", is_passed)

ملخص

تعلمنا كيف ننشئ المتغيرات، قواعد تسميتها، والأنواع الأساسية الأربعة (int, float, str, bool)، وكيفية التحويل بينها. هذه المفاهيم أساسية جداً وستستخدمها في كل درس قادم.
