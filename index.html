الدرس 01: مقدمة إلى لغة Python وتثبيت البيئة

🐍 Python⏱️ 20 دقيقة📊 مبتدئ📝 10 أسئلة

مرحباً بك في أول درس من مسار تعلم لغة Python! في هذا الدرس سنتعرف على اللغة بشكل عام، ونثبت الأدوات اللازمة لنبدأ الكتابة فوراً.

1. ما هي لغة Python؟

Python هي لغة برمجة عالية المستوى، مفسّرة (Interpreted)، وسهلة التعلم. صممها الهولندي جويدو فان روسوم عام 1991، وأصبحت اليوم من أكثر اللغات استخداماً في العالم.

تتميز Python بقراءتها الشبيهة باللغة الإنجليزية، مما يجعلها مثالية للمبتدئين وللمحترفين على حد سواء.

2. لماذا نتعلم Python؟

- سهولة التعلم والقراءة
- مجتمع ضخم ودعم هائل
- تستخدم في: تطوير الويب، تحليل البيانات، الذكاء الاصطناعي، الأتمتة
- مكتبات جاهزة تقريباً لكل شيء
- مطلوبة بشدة في سوق العمل

3. تثبيت Python

اذهب إلى الموقع الرسمي python.org وحمّل أحدث إصدار مستقر. أثناء التثبيت على ويندوز، تأكد من تفعيل خيار "Add Python to PATH".

python --version

4. تثبيت محرر الأكواد VS Code

ننصح بشدة باستخدام Visual Studio Code. حمّله من code.visualstudio.com ثم ثبّت إضافة Python الرسمية.

5. أول تجربة

print("مرحباً بك في عالم Python مع Medo El Jan")

الدرس 02: أول برنامج لك + دالة print و input

🐍 Python⏱️ 25 دقيقة📊 مبتدئ

في هذا الدرس سنكتب أول برامجنا الحقيقية ونتعلم أهم دالتين: print و input.

1. دالة print

print("مرحباً بك في Medo El Jan")
print(100)
print(50 + 30)

2. دالة input

name = input("ما اسمك؟ ")
print("مرحباً بك يا", name)

3. تحويل أنواع البيانات

age = input("كم عمرك؟ ")
age = int(age)
print("بعد 5 سنين سيكون عمرك", age + 5)

4. مثال كامل

print("=== برنامج الترحيب ===")
name = input("اكتب اسمك: ")
age = int(input("اكتب عمرك: "))
print("أهلاً وسهلاً", name)
print("عمرك الحالي:", age)
print("بعد 10 سنوات:", age + 10)

الدرس 03: المتغيرات وأنواع البيانات الأساسية

🐍 Python⏱️ 30 دقيقة📊 مبتدئ

المتغيرات هي صناديق نضع فيها البيانات لنستخدمها لاحقاً.

1. ما هو المتغير؟

name = "Medo"
age = 25
height = 1.75
is_student = True

2. أنواع البيانات الأساسية

int (أعداد صحيحة) — float (عشرية) — str (نصوص) — bool (True/False)

3. معرفة النوع

print(type(100))
print(type(3.14))
print(type("نص"))
print(type(True))

4. التحويل بين الأنواع

num_str = "50"
num_int = int(num_str)
print(num_int + 10)  # 60
